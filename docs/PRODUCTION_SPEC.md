## 3. 声音方案（Qwen3-TTS 纯净基线）

经过多轮听感对比确认，最佳配置为：
- **模型**：`Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice`
- **音色与参数**：`speaker="Serena"`, `language="Chinese"`, `instruct=None`
- **核心原则**：
  1. **不加情绪提示词（`instruct=None`）**：避免过度抑扬顿挫或发声奇怪。
  2. **不切分内部静音、不拉 `atempo` 倍速**：100% 保留原生 24kHz 神经波形的自然气口与尾音；仅在句首句尾做轻柔淡入淡出。
  3. **只读谷底切分字幕**：通过能量低谷定位字幕分句时间点，不改动音频采样本身。
  4. **BGM 自动闪避混音**：`render_core.py` 自动合成轻快四和弦伴奏，人声出现时自动压低背景音量，并在分句/重点转场自动叠加入场波普与清脆叮声。

## 4. 编码质检与纯净网页交付

- **原子写入**：先编码至 `*.tmp.mp4` 再 `os.replace`，避免断电或中断产生坏帧（防止 0～7 秒黑屏无声）。
- **关键帧与清晰度**：`1080×1920`、`25fps`、`libx264` High Profile (`-tune animation -crf 18 -g 50 -movflags +faststart`) + AAC `44.1kHz`。
- **零错校验**：导出后强制跑 `ffmpeg -v error -i <mp4> -f null -` 确认全片零 H.264 NAL 解码错误。
- **纯净视频网页**：`export_pure_video_html()` 会自动控制内嵌视频体积（默认限制在 `<20 MB` 在线预览门槛内），生成仅含 `<video id="v" controls playsinline preload="auto">` 的纯黑极简网页，便于手机浏览器直接预览与系统分享保存相册。
